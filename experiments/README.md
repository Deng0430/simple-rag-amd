# 可公开的实验结果与复核

本目录保存 2026-10-27 两轮本地 Qwen2.5-3B 实验的轻量公开记录。它们与历史 AMD AUP / Qwen3 的部署和推理记录分开。没有继续训练、换题或追加生成。

## 不调用模型的复算

从仓库根目录运行（只用 Python 标准库）：

```bash
python experiments/verify_results.py
```

脚本先检查公开文件哈希，再用仓库中冻结版本的 `condition_metrics.py`，从每条完整原始回答和短答案参考重新计算 EM、Token-F1，并用已保存的 AI 槽位标签累计 Slot-F1。它核对全部 156 个逻辑位置、失败分母、复用关系与九行主表。无需 Ollama、模型权重、网络、文档缓存或本机 `runs/`。

这里只复核评分计算与已提供标签的一致性，不重新做语义标注，也不验证标签本身正确。评分器只忽略操作系统检出时的 CRLF/LF 差异；公开归档文件由本目录 `.gitattributes` 保持原字节。

## 三个数据目录

| 目录 | 数据和对照 | 逻辑位置 |
| --- | --- | ---: |
| `condition_v1/` | 首轮 20 题，A 常规 E5 Top-3，B 条件词优先邻域扩展，C 普通邻域扩展 | 60 |
| `retrieval_v2_new12/` | 新增 12 题探索性验证，D E5、H 等权 BM25/E5 RRF、X 融合后全局补充 | 36 |
| `retrieval_v2_regression20/` | 已暴露的旧 20 题回归，同轮 D/H/X，重新生成 | 60 |

每个目录包括：

- `records.jsonl`：完整模型回答、运行状态、尝试数、复用关联、token 计数、逐项自动分数和 AI 核查标签/理由。错误回答与格式截断均保留；其中的命令不是操作建议，请勿直接执行。
- `questions.json`：原创问题、有限短答案参考、必要槽位 ID。完整来源引文仍见仓库数据集与其来源链接。
- `summary.json`、`paired_differences.csv`、`results_table.csv`：从最终运行目录按原字节复制的汇总和配对表。
- `provenance.json`：模型 digest、tokenizer 和嵌入模型版本、配置、语料及原始文件 SHA-256、相对运行路径与公开范围。
- `checksums.json`：该目录公开数据文件的 SHA-256。

导出过程是字段选择和记录关联，没有改动答案、参考、评分或失败标签。`export_results.py` 是归档导出脚本，只供持有完整本地原始记录时重新导出；普通克隆用户不需要运行它。

## 指标与结论

| 数据 | 组别 | EM | Token-F1 | 条件 Slot-F1（AI 辅助） |
| --- | --- | ---: | ---: | ---: |
| 首轮 20 题 | A / B / C | 35.00 / 40.00 / 35.00% | 47.28 / 56.44 / 49.59% | 42.11 / 45.00 / 43.90% |
| 新增 12 题 | D / H / X | 33.33 / 33.33 / 33.33% | 57.64 / 61.13 / 61.60% | 16.00 / 14.81 / 13.79% |
| 旧 20 题回归 | D / H / X | 40.00 / 40.00 / 45.00% | 52.07 / 52.69 / 57.16% | 42.86 / 38.10 / 52.17% |

首轮 19/20 题 B/C 输入完全相同，不能把两组输出差异归因为策略优势。第二轮全局补充在旧题上改善部分指标，但在新增题上未改善条件完整性；新旧数据分开解释，不合并为“总体提升”。默认网页检索方案未因此替换。

EM/F1 使用保留大小写、命令和标点的中文/英文/符号规则，不是英文 SQuAD 原版。Slot-F1 为 `2TP/(2TP+FP+FN)`，对完整回答评价；它并不等于命令执行成功率。

参考和槽位标注由 AI 辅助依据来源构建，语义评分为隐藏方法标签的 AI 初评及可见组别的协调核查，**人工复核尚未完成**。公开标签是当时记录，不是专家金标准；脚本不会重新用模型打分。

第二轮原始尝试出现服务不完整响应。最终三组统一使用每次独立请求前卸载/重载模型的恢复方案，最终两批 96 个逻辑位置对应 95 个唯一生成条件、97 次生成尝试；其中 2 次首次异常重试成功，1 条完成响应达到输出上限且 JSON 截断。最初失败批次、预热和诊断保存在本机完整归档，不混入最终统计。本目录不是全部运行历史。首轮仍保留最终 1 条服务不完整响应。两轮之间不做速度、能耗或平台性能比较。

## 公开范围与复现限制

完整文档正文、完整提示、模型权重、主机快照、服务日志和源代码运行快照不在此目录再分发；原始 `runs/` 已本地归档。语料快照哈希为 `14b90cbbafc7940105331a8a92e276edf23bc77bad7796c9227a293e837a11b7`（716 段），不要与开发时其他缓存快照混淆。

公开记录足以复算报告中的主表，不等于可以从实时网页重新抓取出逐字相同的历史语料或得到相同模型输出。新运行应使用新目录，并记录各自快照、提示、模型和运行状态。

详细方法、失败分析和恢复过程见 [首轮报告](../docs/condition-experiment-results.md)、[第二轮报告](../docs/retrieval-improvement-v2.md)、[v2 协议](../data/retrieval_eval_v2/PROTOCOL.md)与[运行恢复说明](../data/retrieval_eval_v2/RUNTIME_RECOVERY.md)。
